HTML: É a carcaça e o chassi ele serve para estruturar e marcar o conteúdo textos, links e imagens usando TAGs  

CSS: É a pintura e o design ele cuida do visual das cores das fontes e garante que o site fique bonito tanto no PC quanto no celular 

JavaScript: É o motor e a parte elétrica é o que traz o dinamismo faz as coisas se mexerem valida formulários e permite que o site mude sem precisar recarregar a página

Alert: É aquele pop-up que trava a tela ele só mostra uma mensagem e você tem que dar OK para o código continuar não dá para responder nada para ele  


Prompt: Esse é mais legal porque ele faz uma pergunta e deixa o usuário digitar uma resposta

var: O jeito antigo meio bagunçado que pode ser redeclarado em qualquer lugar  

let: O jeito moderno você pode mudar o valor depois mas não pode criar duas com o mesmo nome no mesmo bloco  

const: Para valores que não vão mudar se não sabe se vai mudar comece sempre com const


Tipos de dados

String: Textos  


Number: Números  


Boolean: Verdadeiro ou Falso  


Undefined/Null: Quando algo está vazio ou não existe
