Checklist de Instalação
   
   Git: Para controlar as versões do seu código localmente (o "salvamento automático" profissional).   
   
   NodeJS: Essencial para rodar JavaScript fora do navegador e gerenciar pacotes.   
   
   VS Code: O seu editor de texto oficial.   
   
   Conta no GitHub: Para guardar seu código na nuvem (repositório remoto).   Configurar SSH: Importante para conectar seu PC ao GitHub de forma segura e não ter que ficar digitando senha toda hora.
